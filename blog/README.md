# Blog / interactive report — code snapshot

A **code‑only** snapshot of the interactive report (public home:
<https://pub.sakana.ai/picbreeder-vlm>). It contains only the hand‑written
front‑end sources — `index.html`, the `breed/` interactive breeder, the
`agent_life/` · `system_overview/` · `transcripts/` sub‑apps, and the
`assets/page/` widget JS/CSS.

Deliberately **not** copied here: generated media (sprite atlases, mp4/mp3,
traversal/lineage frames), large data manifests, and the HuggingFace archive
mirror. Those are regenerated by the `tools/build_*.py` builders in the repo
root and/or fetched from HF at page load, so the pages here will not render
standalone without them.

The canonical, deployable copy lives in the separate `smearle.github.io` repo;
this is a versioned reference snapshot alongside the paper code.
