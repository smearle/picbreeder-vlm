# Blog sourcecode

Code used to generate the interactive report (public home:
<https://pub.sakana.ai/picbreeder-vlm>). We include the
front‑end source code: `index.html`, the `breed/` interactive breeder, the
`agent_life/` · `system_overview/` · `transcripts/` sub‑apps, and the
`assets/page/` widget JS/CSS.

We omit generated media (sprite atlases, mp4/mp3,
traversal/lineage frames), large data manifests, and the HuggingFace archive
mirror. Those can be regenerated by the `tools/build_*.py` builders in the repo
root and/or fetched from HF at page load. The pages here will not render
standalone without them.
